# HiPay Payments module for PrestaShop

[![License](https://img.shields.io/badge/license-AFL%203.0-green)](LICENSE)

Official HiPay payment module for PrestaShop.

---

## Download

> ⚠️ **Do NOT download the "Source code"** — it will not install on your PrestaShop store.  
> Only download the **`hipaypayments.zip`** file from the [releases page](../../releases).

### Which version should I use?

| PrestaShop Version | Module Version |
|--------------------|----------------|
| PrestaShop 1.7.6+  | HiPay Payments **v3.x** |
| PrestaShop 8.x     | HiPay Payments **v4.x** |
| PrestaShop 9.x     | HiPay Payments **v5.x** |

---

## 🚀 Installation

1. Download the correct `.zip` file from the [releases page](../../releases) using the table above.
2. In your PrestaShop back office, go to **Modules > Module Manager**.
3. Click **"Upload a module"** and select the downloaded `.zip` file.
